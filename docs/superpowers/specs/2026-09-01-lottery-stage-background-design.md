# 抽奖大屏舞台背景图设计

**日期：** 2026-09-01  
**状态：** 口头设计已逐段确认；书面规格待审阅  
**范围：** 把观众大屏四页的背景换成已有舞台幕布图，并给文字加半透明深色底。不改后台、配奖页、接口、开奖规则。

---

## 1. 背景与目标

### 1.1 现状

- 观众大屏四页（奖品介绍、报名、抽奖、中奖）共用 `PublicStage` 的 `.stage` 外壳。
- `html` / `body` / `#root` 使用深蓝径向渐变（`stage.css`）。后台 `/admin` 与配奖 `/setup/prizes` 也吃这套全局底，因为它们不使用 `.stage`。
- 奖品图已由 `/uploads` 静态托管 `data/uploads/`。目标图已在 `data/uploads/抽奖背景.jpg`。

### 1.2 已确认需求

| 维度 | 选择 |
|------|------|
| 覆盖页面 | 大屏四页都换背景；后台与配奖页不换 |
| 铺图方式 | 居中、cover 裁切铺满（方案 A） |
| 文字对比 | 保留现有浅色/金色字；在文字区域加半透明深色底（方案 B） |
| 实现策略 | 只改大屏 CSS，继续引用 `/uploads/抽奖背景.jpg`（方案 A） |

### 1.3 目标

- 现场大屏四页看到同一张红色舞台幕布背景，中间内容区文字仍清晰可读。
- 后台、配奖页外观不变。

### 1.4 非目标

- 后台可配置、可上传背景图。
- 把该图拷进 `client/` 静态资源或 `catalog/` 奖品种子。
- 改字色、控制条、滚动名单、中奖动效、四屏流程、接口。
- 为缺失背景图写专门错误页或告警。
- 加载中占位（`.loading`）使用舞台图。

---

## 2. 结构与样式

只改 `client/src/styles/stage.css`。

### 2.1 舞台底图

在 `.stage` 上设置：

- `background-color: var(--bg0)`，作为图片未加载或缺失时的底。
- `background-image: url("/uploads/抽奖背景.jpg")`，与现有奖品图同一套静态路径；中文文件名与现有奖品图一致，不做额外转码层。
- `background-position: center`
- `background-size: cover`
- `background-repeat: no-repeat`

`html` / `body` / `#root` 的渐变保持不变，这样 `/admin`、`/setup/prizes` 以及大屏「加载中…」（`.loading`，不在 `.stage` 内）仍是深蓝底。

主持人条（`.host-bar`）已有自己的深色底，不改。

### 2.2 文字底

在 `.screen` 上加半透明面板，四页共用：

- 背景：`rgba(8, 14, 24, 0.72)`（与控制条同色系）
- 圆角：`18px`（与奖品图框一致）
- 内边距：`1.5rem 1.25rem`，避免标题贴边

`.screen` 现有宽度 `min(960px, 100%)`、居中对齐保持不变。幕布从面板四周露出。切页淡入、滚动、中奖高亮动效不改。

---

## 3. 数据与错误

无新接口、无新配置、无 catalog 拷贝。图继续放在 `data/uploads/抽奖背景.jpg`，由现有 `express.static("/uploads")` 提供。

图片缺失或浏览器加载失败：`.stage` 只显示 `--bg0` 深蓝底，文字面板仍在，页面可操作。不新增错误提示。

---

## 4. 验证

不新增 API 或单元测试；现有页面测试不为背景图改断言。

实现后在浏览器检查：

1. 奖品介绍、报名、抽奖、中奖四页：幕布铺满、居中裁切；文字在深色底上可读；控制条可用。
2. `/admin` 与 `/setup/prizes`：仍为深蓝底，无舞台图。

不单独测「删除背景文件」；缺失时由 CSS 颜色兜底即可。
